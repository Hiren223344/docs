---
title: "Crawl Website"
api: "POST /v1/crawl"
description: "Launch a concurrent sitewide crawl task to index multiple web pages"
---

The crawl endpoint initializes a concurrent, sitewide crawling thread. Starting from your seed URL, Fearch recursively discovers, fetches, renders, and crawls links belonging to the same host up to your configured page limit. Crawls operate asynchronously, providing you with a tracking job receipt.

---

### Request Body

<ParamField body="url" type="string" placeholder="https://example.com" required>
  The seed URL to begin crawling from. Crawl nodes only follow links belonging to the exact same origin host name.
</ParamField>

<ParamField body="limit" type="number" placeholder="10" default="10">
  The maximum number of distinct pages to crawl and parse. Range: `1` to `500`.
</ParamField>

---

### Response Fields

<ResponseField name="success" type="boolean" required>
  Confirms the status of the operation. Returns `true` if the crawl job was successfully queued.
</ResponseField>

<ResponseField name="jobId" type="string" required>
  A unique uuid code identifying the active crawl job. Use this to poll crawl status.
</ResponseField>

<ResponseField name="status" type="string" required>
  The current operational state of the crawl task. Values include:
  - `queued`: Crawl task is waiting for an available crawler thread.
  - `scraping`: Crawl nodes are actively fetching and rendering pages.
  - `completed`: The crawl has finished processing up to the limit or all available pages.
  - `failed`: The crawl task encountered an unrecoverable system exception.
</ResponseField>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "jobId": "abc-123",
  "status": "scraping"
}
```
</ResponseExample>
